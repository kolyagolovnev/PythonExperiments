🎖️ Сослуживцы

GET /users/{UserID}/friends → FriendListItem[] (id, name, surname, photo_url). POST /users/{UserID}/friends {user_id} — только владелец. DELETE /users/{UserID}/friends/{FriendID}.

🛡️ Группы (topic)

name
GET /groups?name=&limit=&offset= — только topic-группы. Личные группы (ленты пользователей) здесь НЕ видны — они в подписках как sub_type:"user".

📌 Подписки

GET /users/{UserID}/subscriptions → SubscriptionListItem[]. sub_type:"group" — topic-группа; sub_type:"user" — личная лента (user_id владельца). DELETE /users/{UserID}/subscriptions/{id}.

📻 Связь · чаты

GET /chats — только мои чаты. Личный чат назван по собеседнику. POST /chats/{ChatID}/messages {text} · GET .../messages?limit&offset. В API нет счётчика непрочитанных — точка лишь сигнализирует «есть чаты».
